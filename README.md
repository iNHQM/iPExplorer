# NHQM IPExplorer — IP Address Intelligence & Network Analysis Tool

**NHQM IPExplorer** is a Python-based IP address investigation and network analysis utility designed to simplify the process of exploring public IP addresses and retrieving detailed network information.

The tool provides an interactive command-line interface (CLI), allowing users to analyze IP addresses, identify network providers, and explore publicly available geolocation and infrastructure data.

### Key Features

- IPv4 address lookup and analysis.
- IP geolocation, including country, region, and city.
- Internet Service Provider (ISP) identification.
- Autonomous System Number (ASN) information.
- Network organization and hosting provider details.
- Timezone and geographic coordinate information.
- Public IP address intelligence.
- Structured network information reports.
- Interactive Windows CMD interface.
- Lightweight and straightforward operation.

**Technologies:** Python, Windows CMD, Networking, IP Geolocation APIs, Network Intelligence, CLI Development.

**Project Goal:** To develop a lightweight and efficient IP intelligence utility that simplifies network investigation, improves access to publicly available IP information, and provides a clear understanding of internet infrastructure through an organized command-line experience.
